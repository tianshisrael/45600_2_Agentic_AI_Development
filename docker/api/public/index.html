Docker + Express

Docker is running

This page is served by an Express API inside a Node.js Docker container. Use these commands to build, run, inspect, and clean up the image.

Build the image docker build -t express-docker-api .
Run the container on port 3005 docker run --rm -p 3005:3005 --name express-api express-docker-api
List running containers docker ps
Show container logs docker logs express-api
Stop the container docker stop express-api
